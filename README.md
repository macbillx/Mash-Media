# Mash Multimedia website

Static website for Mash Multimedia LLC. No build step or package installation is required.

## Files

- `index.html` — home page
- `about.html` — company story, mission, and values
- `services.html` — services and benefits
- `approach.html` — project approach and framework
- `contact.html` — inquiry form
- `styles.css` and `script.js` — shared styling and interactions
- `mash-hero.png` — home page hero image

## Preview locally

Open `index.html` in a browser. The navigation links open the other pages.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. GitHub will provide the published site URL in the Pages settings.

The contact form opens a prefilled email draft addressed to `info@mymash.top`; visitors send it from their own email app.
